# 开发规范

- 本目录是 Vue 3、TypeScript、Vite 静态单页项目；使用 shadcn-vue 和 Tailwind CSS，按需添加组件，避免无必要的依赖和服务端代码。
- 使用 Vue 单文件组件、Tailwind CSS 和原生 CSS；Inter 字体由项目自托管，中文使用系统字体。保持代码清晰、类型严格。
- 保持黑白灰的简约排版，兼容浅色和深色模式；允许页面滚动，确保不同屏幕尺寸和文字放大时内容可访问。
- 使用语义化 HTML，保证颜色对比、键盘焦点、链接名称和图片替代文字可用。不要依赖动画传达信息。
- 保留指定的头像地址、GitHub 链接及两条备案信息，除非用户要求修改。
- 修改后运行 `npm run build`；涉及界面时检查桌面和窄屏、深浅色与键盘操作。部署前确认 Cloudflare 配置及目标账号。
- Git 提交遵循 Conventional Commits：标题使用 `type(scope): description` 格式（scope 按需填写），标题与正文之间留一空行；每次提交必须有正文，说明主要变更及其原因。
- 不要修改仓库根目录的 README，除非用户明确要求。
